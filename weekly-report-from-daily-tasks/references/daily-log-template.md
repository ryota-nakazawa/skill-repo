# Daily Log Template

以下を `./reports/daily/current/YYYY-MM-DD.md` として保存する。

# Daily Task Log YYYY-MM-DD

## プロジェクト進捗
| プロジェクト名 | 進捗記録 | ひとこと |
| --- | --- | --- |
| Aプロジェクト | API実装 60%→80% | 仕様確認待ち |
| Bプロジェクト | 週報自動化スクリプト初版作成 | 欠損日表示は明日対応 |

## メモ
- 補足事項

## 入力ルール
- 1行1プロジェクトで記録する
- `進捗記録` は事実ベースで短く書く
- `ひとこと` は状態や次アクションを短く書く
- 数値があれば入れる（進捗率、件数、時間）
