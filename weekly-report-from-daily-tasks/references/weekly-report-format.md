# Weekly Report Format

週報は `./reports/weekly/current/` に出力し、作成時は対象の1週間だけを集計する。
過去分は必要に応じて `./reports/archive/weekly/` へ移動する。

```md
# 週報 (YYYY-MM-DD 〜 YYYY-MM-DD)

## サマリー
- 対象: X日 / 記録あり: Y日 / 欠損: Z日
- プロジェクト数: P件 / 進捗記録: R件

## プロジェクト別報告（AI整理）
### Aプロジェクト
- 要約: 今週はN件の進捗を記録。開始時点: ... / 直近: ...
- 主要進捗1: ...
- 主要進捗2: ...
- 次アクション/確認1: ...

### Bプロジェクト
- 要約: ...
- 主要進捗1: ...
- 次アクション/確認1: ...

## 補足メモ
- ...

## 今週のひとこと一覧
- [Aプロジェクト][YYYY-MM-DD] ...

## 収集元ファイル
- ...

## 欠損日
- ...
```

## レビュー観点
- 事実と推測を分離できているか
- プロジェクト単位の進捗が追えるか
- ひとことが次アクションや状態判断に使えるか
- プロジェクト別報告に `ひとこと` を混在させていないか
- 日次ログの全レコードが週報に反映されているか
